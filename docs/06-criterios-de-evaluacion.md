## Lo que no se implementó y por qué

| Elemento | Criterio | Justificación |
|---|---|---|
| **Dominio propio** | 10 | No se compró: el nombre DNS de Azure (`*.cloudapp.azure.com`) basta para el HTTPS de staging y evita un gasto fuera del crédito de estudiante (100 USD, con tope de planificación del 80 %: [`costo-y-tamano.md`](despliegue/costo-y-tamano.md)). Cambiarlo sería configuración (registro DNS y certificado), no código |
| **CDN** | 10 | No se contrató ni se configuró. La aplicación es un monolito que sirve sus *assets* desde nginx; un CDN agregaría un servicio de pago y de configuración sin necesidad demostrada por los requisitos (Principio VII, «Simplicidad», de la constitución) |
| **Réplicas de lectura y particiones de la base de datos** | 9 | No se implementaron: una réplica gestionada excede el crédito y el alcance de un MVP con una sola VM. MySQL solo se ajusta por perfil de tamaño (`MYSQL_BUFFER_POOL`, `MYSQL_MAX_CONNECTIONS`) |
| **Caché de aplicación** | 11 | No se implementó en los módulos 1 a 6 (decisión de simplicidad, ADR-006). Su costo se mide en la sesión de carga: la base trabajó mucho (`db` p95 58,6 %), pero el cuello de botella fue el contenedor `app` |
| **API REST** | 5, 12 | No existe: la interfaz es Blade + Livewire en el monolito (RC04, ADR-001). Se documentan en OpenAPI solo los endpoints HTTP reales ([`openapi.yaml`](05-implementacion-y-validacion/openapi.yaml)) |
| **Prueba de usabilidad con 5 usuarios** | 7 | No se realizó (AC08) |

## Cómo se mantiene este documento

Cada estado se copia de la evidencia enlazada. Si una medición cambia (por ejemplo, la sesión con 2000 usuarios o la caché de boletas), se actualiza la fila **y** el documento fuente, no solo esta tabla.
